# Trip Satisfy

## Overview

Trip Satisfy is a comprehensive travel booking portal built with Nuxt.js, designed to simplify travel planning and booking. The platform enables users to search and book flights, hotels, and tour packages worldwide. It also provides B2B travel agents with a credit-based flight booking facility.

The platform integrates with the **Travelport API** to provide flight search and booking services.

## Features

- **Flight Search & Booking:** Search, compare, and book flights through Travelport API integration.
- **Hotel Search & Booking:** Explore and reserve hotels across different destinations worldwide.
- **Tour Package Booking:** Discover and book various travel and tour packages.
- **B2B Credit Booking:** Allows B2B travel agents to book flights using their available credit balance.
- **Travel API Integration:** Connects with Travelport services for flight data and reservation management.
